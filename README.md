# Кабинет торговых OperTool

Статусы заявок и push-уведомления для торговых. Исходники — `agent_app/` в репозитории OperTool;
здесь — опубликованная копия для GitHub Pages плюс `config.js` (адрес Supabase и публичные ключи, не секрет).
Доступ — только по личной ссылке с ключом, которую выдаёт оператор на странице «Торговые».
